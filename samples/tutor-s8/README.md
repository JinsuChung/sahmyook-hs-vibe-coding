# 새봄 학습 도우미 — 8회차 완성본 (과목 튜터 웹앱)

교사가 과목·단원·학습 목표를 정해 두면, 학생이 수업 코드를 넣고 들어와 질문하는 **교육용 AI 에이전트**입니다.
답을 바로 알려 주지 않고, 한 번에 질문 하나씩 던져 학생이 스스로 풀도록 이끕니다(소크라테스식 문답).

예시 설정은 **새봄고등학교(가상) 1학년 통합과학 · 역학적 에너지 보존**입니다. `lib/tutor-config.ts` 한 파일만 고치면 다른 과목·단원으로 바꿀 수 있습니다.

> **먼저 읽어 주세요.** 이 앱은 수업 실습용 완성본입니다. 실제 학생에게 쓰기 전에 아래 [미성년자가 쓰는 서비스라는 점](#미성년자가-쓰는-서비스라는-점-운영-전-필독)과 [실제 수업에 쓰기 전 체크리스트](#실제-수업에-쓰기-전-체크리스트)를 반드시 확인하세요.

## 무엇이 들어 있나요

| 화면 | 내용 |
| --- | --- |
| 첫 화면 | **수업 코드** 입력 → **들어가기** |
| 채팅 화면 | 위쪽에 과목·단원, **이 단원의 학습 목표**(펼쳐 보기), 고지 문구, **대화 초기화** 버튼. 아래쪽에 입력칸과 **보내기** 버튼, 남은 질문 수 |

튜터가 하는 일과 하지 않는 일:

- 정답 대신 다음 한 걸음을 떠올리게 하는 질문을 **한 번에 하나** 합니다.
- 같은 곳에서 두세 번 막히면 힌트를 **한 단계씩** 올립니다(개념 짚기 → 조건·식 좁히기 → 첫 단계만 함께). 마지막 계산과 결론은 학생이 말하게 합니다.
- 과제·수행평가를 **대신 써 주지 않습니다.** 방법을 안내합니다.
- 단원 **범위 밖 질문은 정중히 거절**하고 선생님께 묻도록 안내합니다.
- **개인정보를 묻지 않습니다.** 학생이 적어도 되풀이하거나 활용하지 않습니다.
- 자해·학교폭력 같은 **위기 신호가 보이면 공부 이야기를 멈추고** 담임·상담 선생님, 청소년상담전화 1388, 자살예방 상담전화 109, 학교폭력 신고 117, 긴급 시 112·119를 안내합니다.

## 실행 방법

준비물: [Node.js](https://nodejs.org) LTS 버전, [Claude Console](https://platform.claude.com) 계정과 API 키(선불 크레딧 필요).

1. **Console에서 월 사용 한도를 먼저 정합니다**([비용 한도 설정](#비용-한도-설정-꼭-하세요) 참고). 그다음 API 키를 발급합니다.
2. `.env.local.example`을 복사해 `.env.local`로 이름을 바꾸고 값을 넣습니다. 키는 Claude Code 채팅창에 붙여 넣지 말고 파일에 직접 넣으세요.
3. 실행합니다.

```bash
npm install
npm run dev
```

http://localhost:3000 을 열고, `.env.local`에 적은 수업 코드로 들어갑니다.

## 환경변수

| 이름 | 필수 | 설명 |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | 예 | Claude API 키. **서버에서만** 읽습니다 |
| `CLASS_CODE` | 예 | 수업 코드(입장용 암호). **서버에서만** 비교합니다. 대소문자는 구분하지 않습니다. 비어 있으면 아무도 들어올 수 없습니다 |
| `CLAUDE_MODEL` | 아니요 | 사용할 모델. 비우면 `claude-haiku-5-5` |

세 값 모두 `NEXT_PUBLIC_`이 붙지 않아 브라우저로 내려가지 않습니다.

## 내 수업에 맞게 고치기

| 파일 | 하는 일 | 고칠 일 |
| --- | --- | --- |
| `lib/tutor-config.ts` | 과목·단원·학습 목표·다루는 범위·자주 하는 오개념·말투·예시 질문·사용 제한 | **주로 여기만 고칩니다** |
| `lib/tutor-prompt.ts` | 설정으로 튜터의 지시문(시스템 프롬프트)을 만듭니다. 가르치는 방식, 하지 않는 일, 위기 대응 규칙이 적혀 있습니다 | 튜터의 행동을 바꾸고 싶을 때 |
| `eval/questions.md` | 배포 전에 직접 넣어 보는 시험 질문 15개와 기대 동작 | 내 단원에 맞게 질문을 바꿉니다 |
| `app/api/chat/route.ts` | 대화 서버. 수업 코드 확인 → 길이 확인 → 횟수 제한 → Claude API 호출(스트리밍) | 보통 고치지 않습니다 |
| `app/api/enter/route.ts` | 첫 화면의 수업 코드 확인 | 보통 고치지 않습니다 |
| `lib/access.ts` | 수업 코드 비교, 여러 번 틀리면 잠시 막기 | 보통 고치지 않습니다 |
| `lib/rate-limit.ts` | 요청 횟수 제한(메모리 방식) | 보통 고치지 않습니다 |
| `components/tutor.tsx` | 학생 화면(수업 코드 입력, 채팅) | 문구를 바꾸고 싶을 때 |
| `app/globals.css` | 색·간격 | 꾸밈을 바꾸고 싶을 때 |

Claude Code에게 이렇게 말해 보세요: "lib/tutor-config.ts를 2학년 수학 '지수함수와 로그함수' 단원으로 바꿔 줘. 학습 목표는 내가 불러 줄게."

**고친 뒤에는 반드시 `eval/questions.md`의 질문을 다시 넣어 보세요.** 지시문 한 줄이 튜터의 행동을 바꿉니다.

## 안전장치와 그 한계

| 장치 | 어디에 | 솔직한 한계 |
| --- | --- | --- |
| 수업 코드 | `lib/access.ts` | 아무나 들어와 요금을 쓰는 것을 막는 문턱입니다. **학생 개인 확인이나 연령 확인이 아닙니다.** 코드가 퍼지면 바꿔야 합니다 |
| API 키는 서버에서만 | `app/api/chat/route.ts` | — |
| 대화당 질문 수(20), 메시지 길이(500자), 답변 분량(`max_tokens` 1,500) | `lib/tutor-config.ts`의 `limits` | 화면이 대화를 통째로 다시 보내는 방식이라, 화면을 조작하면 대화 기록을 꾸며 보낼 수 있습니다. 길이와 순서는 서버가 검사합니다 |
| 요청 횟수 제한(1분 6회, 하루 80회, 전체 하루 2,000회) | `lib/rate-limit.ts` | **서버 메모리에만 적습니다.** Vercel 같은 서버리스에서는 서버가 잠들었다 깨거나 여러 대로 나뉘면 횟수가 초기화되거나 따로 세어집니다. 대략의 과속 방지턱일 뿐이고, **비용의 진짜 상한선은 Console 사용 한도**입니다 |
| 범위 밖·대필 거절, 개인정보를 묻지 않음, 위기 대응 | `lib/tutor-prompt.ts`의 지시문 | 지시문은 AI의 행동을 **이끌 뿐 보장하지 않습니다.** 그래서 배포 전에 시험 질문으로 확인하고, 수업 중에는 교사가 함께 있어야 합니다 |
| 대화를 저장하지 않음 | 서버·화면 모두 | 대화는 학생 브라우저의 메모리에만 있고 새로 고치면 사라집니다. 서버 기록에도 본문을 남기지 않습니다. 그 대신 **교사가 나중에 대화를 볼 방법이 없습니다.** 대화 내용은 답변을 만들기 위해 Anthropic API로 전송됩니다 |
| "AI가 만든 답변이며 틀릴 수 있어요" 고지 | 첫 화면과 채팅 화면 | — |

## 미성년자가 쓰는 서비스라는 점 (운영 전 필독)

아래 내용은 **2026-11-16에 Anthropic 공식 문서를 직접 확인**해 정리한 것입니다. 정책은 바뀔 수 있으니 운영 전에 원문을 다시 확인하세요. 요약과 원문이 다르면 원문이 우선입니다.

### 1. 학생은 Claude.ai에 직접 가입할 수 없습니다

Anthropic의 소비자용 서비스(Claude.ai, Claude 앱)는 **만 18세 이상**만 쓸 수 있고, 가입할 때 18세 이상임을 확인합니다.

- [Age assurance on Claude](https://support.claude.com/en/articles/15171100) (Claude 도움말)

그래서 고등학생이 직접 쓰는 도구는, 교사나 학교가 **Claude API로 만든 앱**(바로 이런 형태)이 됩니다. 이때 그 앱을 만든 쪽(교사·학교)이 Anthropic의 이용 정책을 지킬 책임을 집니다.

### 2. 미성년자가 쓰는 앱에는 Anthropic의 추가 요건이 붙습니다

- [Usage Policy](https://www.anthropic.com/legal/aup): 미성년자가 직접 상호작용할 수 있는 제품(API를 붙인 제품 포함)은 도움말 문서의 **추가 가이드라인과 관련 법률을 모두 지켜야** 한다고 적혀 있습니다. 이 정책에서 미성년자는 만 18세 미만입니다.
- [Responsible Use of Anthropic's Models: Guidelines for Organizations Serving Minors](https://support.claude.com/en/articles/9307344-responsible-use-of-anthropic-s-models-guidelines-for-organizations-serving-minors): 미성년자에게 서비스를 제공하는 조직이 갖춰야 할 안전장치를 설명합니다. 확인한 요지는 다음과 같습니다.
  - 용도에 맞는 **추가 안전 기능**을 갖출 것. 예로 드는 것: 의도한 사용자만 쓰게 하는 연령 확인, 부적절한 내용을 걸러 내는 콘텐츠 조정·필터링, 문제를 찾아 대응하는 모니터링·신고 체계, 미성년자를 위한 안전한 사용 교육 자료.
  - 아동 안전·개인정보 관련 **법규를 지킬 책임은 운영하는 조직**에 있으며, 준수 사실을 누리집 등에 밝힐 것.
  - 사용자가 사람이 아니라 **AI와 대화하고 있음을 반드시 알릴 것.**
  - Anthropic이 준수 여부를 주기적으로 점검하며, 위반이 많은데도 요청받은 조치를 하지 않으면 계정이 정지·해지될 수 있음.
- [Child safety guidance for developers](https://support.claude.com/en/articles/15591275): 개발자가 지켜야 할 아동 안전 의무와 참고 자료를 안내합니다.

### 3. 이 완성본이 갖춘 것과 갖추지 못한 것

| 가이드라인에서 말하는 것 | 이 완성본 | 운영하려면 더 필요한 것 |
| --- | --- | --- |
| AI임을 알리기 | 첫 화면·채팅 화면의 고지 문구, 지시문의 "너는 AI이다" | 첫 수업에서 말로도 안내 |
| 의도한 사용자만 쓰게 하기 | 수업 코드 | 수업 코드는 연령 확인이 아닙니다. 학교 계정 로그인 등은 학교·교육청과 상의 |
| 부적절한 내용 걸러 내기 | 지시문의 범위 제한·거절 규칙, 모델 자체의 안전장치 | 별도 필터는 없습니다. 시험 질문으로 확인하고 교사가 함께 있는 자리에서 사용 |
| 모니터링·신고 | **없음**(대화를 저장하지 않음) | 학생이 이상한 답을 보면 화면을 선생님께 보여 주는 절차를 정하세요. 대화를 기록하려면 개인정보 처리 근거·고지·보관 기간부터 학교 절차로 정해야 합니다 |
| 안전한 사용 교육 | 화면의 짧은 고지뿐 | 사용 전 5분 안내: AI는 틀릴 수 있다, 개인정보를 쓰지 않는다, 답을 베끼는 도구가 아니다 |
| 법규 준수와 공개 | 해당 없음 | 개인정보 보호법, 학교·교육청의 AI·에듀테크 활용 지침, 학교 내부 승인 절차 확인 |

### 4. 학교·교육청 지침을 먼저 확인하세요

이 앱은 학생이 쓴 글을 해외에 있는 AI 서비스(Anthropic API)로 보냅니다. 운영 전에 다음을 학교 안에서 확인하세요.

- 소속 교육청·학교의 생성형 AI 및 에듀테크 활용 지침, 학습지원 소프트웨어 선정 절차
- 학생·보호자 안내와 동의가 필요한지(개인정보 보호법, 학교 개인정보 처리방침)
- 학교 정보 담당 부서와 관리자의 승인

지침마다 요구하는 내용이 다르고 자주 바뀝니다. 이 문서는 법률 자문이 아니며, 판단이 어려우면 학교의 개인정보 보호 업무를 맡은 선생님이나 교육청에 문의하세요.

## 비용 한도 설정 (꼭 하세요)

API는 쓴 만큼 요금이 나옵니다. 앱의 횟수 제한이 뚫리거나 고장 나도 요금이 일정 금액을 넘지 않게, **Console에서 월 사용 한도를 먼저 걸어 둡니다.**

1. [Claude Console의 Spend limits 화면](https://platform.claude.com/settings/spend-limits)을 엽니다.
2. **Monthly spend limit** 옆의 **Set limit**(이미 값이 있으면 **Adjust limit**)을 누릅니다.
3. 한 달에 써도 되는 금액을 넣습니다. 한도에 닿으면 그달에는 API 요청이 거절되고, 학생 화면에는 "지금은 도우미를 쓸 수 없어요. 선생님께 알려 주세요."라는 안내가 뜹니다.

이 앱 전용 워크스페이스를 따로 만들어 그 워크스페이스에만 한도를 거는 방법도 있습니다(기본 워크스페이스에는 한도를 걸 수 없습니다). 자세한 내용과 최신 메뉴 이름은 공식 문서를 확인하세요: [Rate limits – Spend limits](https://platform.claude.com/docs/en/api/rate-limits#spend-limits), [Workspaces](https://platform.claude.com/docs/en/manage-claude/workspaces). (2026-11-16 확인)

**비용 어림** (2026-11-16 기준 Claude Haiku 5.5: 입력 100만 토큰당 $0.10, 출력 $0.50. [공식 요금표](https://platform.claude.com/docs/en/about-claude/pricing)): 대화가 길어질수록 앞의 대화를 다시 보내므로 입력이 늘어납니다. 질문 20번짜리 대화 하나를 넉넉히 잡아도 몇 센트를 넘기 어렵고, 한 반 28명이 한 차시 쓰는 비용은 보통 1달러에 못 미칩니다. 다만 어림일 뿐이니 첫 수업 뒤 Console의 사용량 화면에서 실제 값을 확인하세요.

## 배포 방법 (Vercel)

1. 이 폴더를 GitHub 저장소에 올립니다. `.env.local`은 `.gitignore`에 들어 있어 올라가지 않습니다. 저장소는 비공개(Private)로 만드는 것을 권합니다.
2. Vercel에서 저장소를 가져온 뒤 **Settings → Environment Variables**에 `ANTHROPIC_API_KEY`와 `CLASS_CODE`를 등록합니다.
3. 환경변수를 넣거나 바꾼 뒤에는 **다시 배포(Redeploy)** 해야 반영됩니다. 수업 코드를 바꿀 때도 같습니다.
4. 배포 주소로 들어가 `eval/questions.md`의 질문을 다시 넣어 봅니다.

메뉴 이름이 다르게 보이면 [Vercel 공식 문서](https://vercel.com/docs)를 확인하세요.

- [ ] Anthropic의 [Usage Policy](https://www.anthropic.com/legal/aup)와 [미성년자 대상 가이드라인](https://support.claude.com/en/articles/9307344-responsible-use-of-anthropic-s-models-guidelines-for-organizations-serving-minors)을 직접 읽었다.
- [ ] Console에서 월 사용 한도를 걸었다.
- [ ] `lib/tutor-config.ts`의 과목·단원·학습 목표·범위가 내 수업과 맞다.
- [ ] `eval/questions.md`의 질문을 배포된 주소에서 모두 넣어 보고 결과를 적었다. 기대와 다른 답이 있으면 지시문을 고치고 다시 시험했다.
- [ ] 수업 코드를 추측하기 어렵게 정했고, 수업 시간에만 알려 준다. 단원이 끝나면 코드를 바꾸거나 배포를 내린다.
- [ ] 학생에게 미리 안내했다: AI의 답은 틀릴 수 있다, 개인정보를 쓰지 않는다, 과제를 대신 해 주는 도구가 아니다, 이상한 답을 보면 선생님께 화면을 보여 준다.
- [ ] 교사가 함께 있는 수업 시간에 쓴다. 학생이 힘든 이야기를 꺼냈을 때 이어받을 사람(담임·상담 교사)을 정해 두었다.
- [ ] 이 도우미의 답을 평가나 학교생활기록부의 근거로 쓰지 않는다. 평가와 기록의 판단은 교사가 한다.

## 가상 데이터 고지

학교 이름(새봄고등학교)과 예시 설정은 실습용으로 지어낸 것입니다. 학습 목표는 예시이므로 실제 수업에서는 교과서와 평가계획에 맞춰 바꾸세요.
