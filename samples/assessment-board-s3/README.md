# 수행평가 일정 보드 — 3회차 완성본 (정적 데이터)

새봄고등학교(가상)의 학년·과목별 수행평가 마감을 D-day 순으로 보여 주는 한 화면짜리 웹앱입니다.
3회차에서 Claude Code로 만들고, GitHub에 올리고, Vercel로 배포하는 보드의 완성본입니다.

- 마감이 가까운 순서로 카드가 놓입니다.
- 7일 안에 마감인 평가는 빨간 테두리로, 이미 지난 평가는 흐리게 보입니다.
- 학생 이름·성적 같은 개인정보가 없어서 공개 주소로 배포해도 안전한 주제입니다.

## 실행 방법

[Node.js](https://nodejs.org) LTS 버전이 설치돼 있어야 합니다.

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:3000 을 엽니다. 끌 때는 터미널에서 `Ctrl + C`를 누릅니다.

## 폴더 구조

| 파일 | 하는 일 |
| --- | --- |
| `data/assessments.ts` | 평가 목록(가상 데이터 10건). 일정을 바꾸려면 이 파일만 고칩니다 |
| `app/page.tsx` | 화면. 마감일 순 정렬, D-day 계산(한국 시간 기준), 임박·마감 표시 |
| `app/globals.css` | 색·간격 같은 꾸밈 |
| `app/layout.tsx` | 페이지 제목과 공통 틀 |
| `CLAUDE.md` | Claude Code가 이 프로젝트에서 지킬 규칙 |

## 환경변수

없습니다. 이 버전은 키나 비밀번호를 쓰지 않습니다.

## 배포 방법 (Vercel)

1. 이 폴더를 GitHub 저장소에 올립니다(`node_modules`, `.next`는 `.gitignore`에 들어 있어 올라가지 않습니다).
2. [Vercel 대시보드](https://vercel.com/dashboard)에서 **Add New → Project**로 저장소를 고르고 **Deploy**를 누릅니다.
3. 그다음부터는 `git push`만 하면 1분쯤 뒤 배포 주소에 반영됩니다.

메뉴 이름이 다르게 보이면 [Vercel 공식 문서](https://vercel.com/docs)를 확인하세요.
