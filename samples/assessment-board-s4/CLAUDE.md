# 작업 규칙
- 답변과 화면 문구는 한국어로 쓴다
- 기능 하나를 마치면 한글 메시지로 커밋한다
- 키는 .env.local과 Vercel 환경변수에만 둔다. ANTHROPIC_API_KEY와 Supabase 비밀 키(service_role)는 브라우저 코드에 절대 넣지 않는다
- Claude API는 app/api 아래 서버 코드에서만 호출한다
- AI 결과는 초안이다. 저장은 교사가 확인한 뒤 직접 누르게 하고, 자동 등록 기능은 만들지 않는다
- 학생 이름·학번·성적 같은 개인정보는 이 앱에 넣지 않는다. 데이터는 전부 가상이다
