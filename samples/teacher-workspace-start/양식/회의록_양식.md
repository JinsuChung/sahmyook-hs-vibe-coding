# 회의록 양식 (새봄고등학교)

회의가 끝난 날 안에 정리합니다. 누가 무슨 말을 했는지 받아 적지 않고, **결정한 것과 할 일**을 남깁니다.

## 틀

```text
〈회의 이름〉 회의록

- 일시: 2026. 〈월〉. 〈일〉.(〈요일〉) 〈시작〉–〈끝〉
- 장소: 〈장소〉
- 참석: 〈참석자〉 (불참: 〈불참자와 사유〉)
- 기록: 〈기록자〉

1. 안건
   가. 〈안건 1〉
   나. 〈안건 2〉

2. 논의 내용 (안건별로 두세 줄)
   가. 〈안건 1〉: 〈나온 의견의 요지〉
   나. 〈안건 2〉: 〈나온 의견의 요지〉

3. 결정 사항
   - 〈결정 1〉
   - 〈결정 2〉

4. 할 일
   | 할 일 | 담당 | 기한 |
   | - | - | - |
   | 〈할 일〉 | 〈담당자〉 | 2026. 〈월〉. 〈일〉.(〈요일〉) |

5. 다음 회의: 2026. 〈월〉. 〈일〉.(〈요일〉) 〈시각〉, 〈장소〉
```

## 쓰는 요령

- 결정 사항은 "~하기로 함"으로 끝냅니다.
- 할 일에는 담당과 기한을 빠뜨리지 않습니다. 정해지지 않았으면 "담당 미정", "기한 미정"으로 적습니다.
- 학생 개인에 관한 논의(생활지도·상담·성적)는 이름을 적지 않고 "해당 학생"으로 씁니다.
- 한 쪽을 넘기지 않습니다.
