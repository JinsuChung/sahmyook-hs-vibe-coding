# 새봄고 교무수첩 (5회차 시작본)

교사 한 사람의 업무 폴더를 Claude Code 에이전트의 작업장으로 만드는 실습 자료입니다.
주인공은 새봄고등학교(가상) 1학년 3반 담임, 국어 교사 김가온 선생님(1학년 부장)이고, 오늘은 2026년 11월 16일(월)이라고 가정합니다.

## 꼭 읽어 주세요

- 이 폴더의 학교·기관·인물·문서번호·일정은 **모두 교육용 가상 데이터**입니다. 실제 기관·인물과 관계없습니다.
- **실제 학생 정보는 넣지 마세요.** 이름·학번·연락처·성적·상담 내용·건강·가정 정보가 든 파일, 나이스(NEIS)에서 내려받은 원본 파일은 이 폴더에 두지 않습니다.
- 내 업무에 써 보고 싶다면 학교·교육청 지침을 먼저 확인하고, 학생을 알아볼 수 있는 정보는 지우거나 가명(임의 번호)으로 바꾼 사본으로 연습하세요.
- 성적과 학교생활기록부의 판단과 책임은 교사에게 있습니다. 에이전트는 초안·점검·취합을 돕는 보조입니다.

## 폴더 구성

| 위치 | 내용 |
| - | - |
| `CLAUDE.md` | 에이전트가 세션마다 읽는 업무 규칙. 지금은 초안이고 5회차에서 채웁니다. |
| `받은공문/` | 가상 공문 7건(pdf 4, docx 2, txt 1). 제출 기한과 방법이 서로 다릅니다. |
| `양식/` | 가정통신문·회의록·주간업무 양식. 새봄고 문체 예시가 들어 있습니다. |
| `보낸문서/` | 결과물이 쌓이는 곳. 지난 가정통신문 2편이 문체의 본보기로 들어 있습니다. |
| `학사일정_2026-2.csv` | 2026-11-16부터 2027-02-10까지의 가상 학사일정(날짜, 요일, 행사, 대상 학년, 비고). |
| `생기부_초안/` | 가상 학생 8명의 국어 세부능력 및 특기사항 초안(파일 이름은 임의 학번). 6회차 점검 실습용이라 일부러 문제를 심어 두었습니다. |

## 시작하는 법

1. 이 폴더를 문서 폴더처럼 찾기 쉬운 곳에 둡니다.
2. Claude Code에서 이 폴더를 엽니다(데스크톱 앱이면 폴더 선택, 터미널이면 이 폴더로 이동한 뒤 `claude`).
3. 강의 사이트 5회차 페이지의 순서를 따라 합니다.

한글(HWP) 문서를 맡기고 싶을 때는 한글에서 PDF나 DOCX로 저장한 사본을 넣는 것이 기본 요령입니다.
