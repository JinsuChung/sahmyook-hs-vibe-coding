# 실행 기록 (예시)

`run-weekly.sh`나 `run-weekly.ps1`을 돌리면 실행할 때마다 `자동화/실행기록.md` 끝에 아래와 같은 기록이 한 덩어리씩 붙습니다. 이 파일은 석 주 동안 쌓인 기록이 어떤 모습인지 보여 주는 예시입니다.

- 제목 줄(실행 시각, 기준일, 종료 코드)은 스크립트가 붙이고, 그 아래는 에이전트의 마지막 답입니다.
- 종료 코드 0은 정상 종료, 0이 아닌 값은 실패입니다.
- 데스크톱 앱의 예약 작업은 이 파일을 쓰지 않습니다. 앱의 예약 작업 상세 화면에 있는 실행 내역에서 실행마다의 대화를 열어 볼 수 있고, 브리핑 파일 끝의 "실행 메모"에도 같은 내용이 남습니다.

기록을 볼 때 확인할 것

1. 실행된 날짜가 빠진 주는 없는가
2. 종료 코드가 0인가
3. "읽지 못한 파일"과 "하지 못한 일"에 무엇이 적혔는가
4. 저장했다는 파일이 실제로 `보낸문서/`에 있는가
