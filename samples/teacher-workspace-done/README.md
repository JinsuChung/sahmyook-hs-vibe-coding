# 새봄고 교무수첩 (7회차 완성본)

교사 한 사람의 업무 폴더를 Claude Code 에이전트의 작업장으로 만든 실습 자료의 완성본입니다. 5회차 시작본에 5–7회차에서 만드는 것을 모두 더했습니다.
주인공은 새봄고등학교(가상) 1학년 3반 담임, 국어 교사 김가온 선생님(1학년 부장)이고, 오늘은 2026년 11월 16일(월)이라고 가정합니다.

## 꼭 읽어 주세요

- 이 폴더의 학교·기관·인물·문서번호·일정은 **모두 교육용 가상 데이터**입니다. 실제 기관·인물과 관계없습니다.
- **실제 학생 정보는 넣지 마세요.** 이름·학번·연락처·성적·상담 내용·건강·가정 정보가 든 파일, 나이스(NEIS)에서 내려받은 원본 파일은 이 폴더에 두지 않습니다.
- 성적과 학교생활기록부의 판단과 책임은 교사에게 있습니다. 생기부 점검 스킬은 글을 고쳐 쓰지 않고 지적만 합니다.
- 완성본은 정답지가 아니라 한 가지 본보기입니다. 스킬과 규칙은 내 학교와 내 업무에 맞게 고쳐 쓰세요.
