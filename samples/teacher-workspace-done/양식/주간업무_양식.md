# 주간업무 양식 (새봄고등학교 1학년부)

매주 월요일 아침에 한 주를 정리합니다. 한 화면에 들어오는 분량으로 씁니다.

## 틀

```text
주간 업무 브리핑 — 2026. 〈월〉. 〈일〉.(월) 주

1. 이번 주 일정
   | 날짜 | 행사 | 대상 | 준비할 것 |
   | - | - | - | - |
   | 〈월〉. 〈일〉.(〈요일〉) | 〈행사〉 | 〈대상〉 | 〈준비할 것 또는 "없음"〉 |

2. 기한이 다가오는 공문 (2주 이내)
   | 기한 | 남은 날 | 공문 | 할 일 | 제출 방법 |
   | - | - | - | - | - |
   | 〈월〉. 〈일〉.(〈요일〉) | D-〈일수〉 | 〈제목〉 | 〈할 일〉 | 〈방법〉 |

3. 지난주 보낸 문서의 후속 조치
   - 〈문서 이름〉: 〈해야 할 일과 기한〉

4. 이번 주에 먼저 할 일 세 가지
   1) 〈할 일〉
   2) 〈할 일〉
   3) 〈할 일〉

5. 확인이 필요한 것
   - 〈읽지 못한 파일, 날짜가 불분명한 문서 등〉
```

## 쓰는 요령

- 날짜는 `11. 20.(금)`처럼 요일을 함께 적습니다.
- 남은 날은 오늘을 D-0으로 셉니다. 7일 이내는 앞에 `★`를 붙입니다.
- 근거가 된 파일 이름을 괄호 안에 적어 둡니다. 사람이 원본을 다시 확인할 수 있어야 합니다.
- 추측으로 채우지 않습니다. 모르는 것은 "확인 필요"로 적습니다.
