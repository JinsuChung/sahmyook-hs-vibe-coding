# 생기부 문구 점검

점검 대상: $ARGUMENTS
(위가 비어 있으면 `생기부_초안/` 폴더의 txt 파일 전체를 점검한다.)

## 원칙 (항상 지킨다)

- **글을 고쳐 쓰지 않는다. 지적만 한다.** 대상 파일을 수정하지 않고, 고쳐 쓴 문장이나 대신 쓸 문장도 내놓지 않는다.
- **판단과 수정은 교사가 한다.** 모든 지적은 "의심"이다. 실제로 기재할 수 없는 내용인지, 어떻게 고칠지는 학생을 직접 관찰한 교사가 정한다.
- 바이트 수는 눈으로 세지 않는다. 반드시 아래 스크립트를 실행해서 나온 숫자만 쓴다.
- 학생을 알아볼 수 있는 정보(이름, 연락처)가 글에 있으면 보고서에 옮겨 적지 말고 "개인정보 포함"이라고만 알린다.

## 절차

1. 바이트 수 세기: 아래 명령을 실행한다. 대상이나 한도를 따로 받았으면 그 값으로 바꾼다.

   ```bash
   python3 "${CLAUDE_SKILL_DIR}/scripts/byte_count.py" 생기부_초안 --limit 1500
   ```

   - `python3`가 없으면 `python`으로 실행한다.
   - 한도 기본값은 1500바이트(한글 500자)다. 영역에 따라 한도가 다르므로 사용자가 한도를 말하면 `--limit`를 그 값으로 바꾼다.
   - 스크립트를 실행하지 못하면 바이트 수를 추정하지 말고, 실행하지 못했다는 사실과 이유를 알린 뒤 나머지 점검만 한다.

2. 기준 읽기: [reference/기재요령_요약.md](reference/기재요령_요약.md)를 읽는다. 기재할 수 없는 내용의 근거는 이 파일의 항목 번호로 댄다.

3. 파일마다 본문을 읽고 아래 네 가지를 점검한다.
   1) 바이트 수와 한도 초과 여부 (1번 스크립트 결과 그대로)
   2) 기재할 수 없는 내용으로 의심되는 표현: 해당 표현을 따옴표로 짧게 인용하고 근거 항목(예: 3-나, 5-4)을 붙인다
   3) 사실 근거 없이 추상적인 문장: 무엇을 했는지(활동, 산출물, 변화)가 없는 칭찬과 미사여구
   4) 맞춤법과 띄어쓰기: "틀린 표기 → 바른 표기"로만 알린다

4. 보고한다. 파일로 저장하지 않고 대화로 보고한다.

## 보고 형식

먼저 요약 표를 보인다.

| 파일 | 바이트 / 한도 | 한도 | 기재 금지 의심 | 추상적 문장 | 맞춤법 |
| - | - | - | - | - | - |
| 10301.txt | 1,108 / 1,500 | 이내 | 없음 | 없음 | 없음 |

그다음 지적이 있는 파일만 파일별로 적는다.

- 한도: 몇 바이트 초과인지
- 기재 금지 의심: "인용" — 근거 항목 — 왜 의심되는지 한 줄
- 추상적 문장: "인용" — 어떤 사실이 빠져 있는지 한 줄
- 맞춤법: 틀린 표기 → 바른 표기

마지막에 아래 두 줄을 붙인다.

- 이 점검은 참고용이며 해당 학년도 기재요령 원문과 나이스 화면으로 최종 확인해야 한다는 것
- 수정은 선생님이 직접 하시고, 고친 뒤 다시 점검을 맡길 수 있다는 것

## 참고

- 스크립트 사용법: `scripts/byte_count.py` 맨 위 설명 참고. 파일 하나만 셀 수도 있고, `--newline-bytes`로 줄바꿈 바이트를 바꿀 수 있다.
- 1학년 공통국어처럼 공통과목 1·2를 합산하는 과목은 두 학기 글을 합친 길이로 봐야 한다(기재요령_요약 1번).
