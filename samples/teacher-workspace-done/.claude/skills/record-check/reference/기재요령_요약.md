## 1. 입력 가능 최대 글자 수 (208쪽 표, 한글 기준)

| 영역 | 세부 항목 | 최대 글자 수 | 바이트로 |
| - | - | - | - |
| 교과학습발달상황 | 과목별 세부능력 및 특기사항 | 과목별 500자 | 1,500 |
| 교과학습발달상황 | 개인별 세부능력 및 특기사항 | 500자 | 1,500 |
| 창의적 체험활동상황 | 자율·자치활동 특기사항(3학년은 자율활동) | 500자 | 1,500 |

| 창의적 체험활동상황 | 봉사활동실적 활동내용 | 실적별 50자 | 150 |

- 표의 일부만 옮겼습니다. 인적·학적사항, 수상경력, 자격증, 전공·과정 등 나머지 항목은 원문 표를 보세요.
- "바이트로" 열은 표의 글자 수에 3을 곱해 이 파일에서 계산해 넣은 값입니다.
- 최대 글자 수는 학년 단위 기준입니다. 과목별 세부능력 및 특기사항만 예외로 과목별 기준입니다.
- **공통과목 1·2는 합산 500자**: 2022 개정 교육과정을 적용받는 2026학년도 1–2학년의 공통과목(공통국어, 공통수학, 공통영어, 통합사회, 통합과학, 한국사, 과학탐구실험)은 1과 2를 합쳐 500자 안에서 기재합니다. 예를 들어 1학년 공통국어1에 300자를 썼다면 공통국어2에는 200자가 남습니다.
- 전공실무과목은 학기별 500자입니다.
- 글자 수가 넘친다고 그 내용을 다른 영역에 옮겨 적지 않습니다(28쪽).
- 과목별 세부능력 및 특기사항은 최대 글자 수를 넘지 않는 범위에서 교사가 자율적으로 입력합니다(95쪽).

## 2. 바이트 세는 법 (208쪽 표 아래 주석)

- 교육정보시스템(나이스)의 입력 단위는 Byte입니다.
- 한글 1자 = 3Byte, 영문·숫자 1자 = 1Byte, 엔터(Enter) = 1Byte
- 그래서 "500자"는 한글만 썼을 때의 이야기이고, 실제 한도는 1,500Byte입니다. 띄어쓰기가 많으면 500자를 넘겨도 1,500Byte 안에 들어올 수 있습니다.

확인 필요
- 공백과 문장부호: 기재요령 주석에는 한글, 영문·숫자, 엔터만 나와 있습니다. `byte_count.py`는 공백과 영문 문장부호를 1Byte로, 그 밖의 문자를 UTF-8 바이트 수로 셉니다(가운뎃점 ·은 2Byte, 둥근 따옴표 ‘ ’ “ ”는 3Byte). 이런 문자가 많은 글은 나이스 화면에 표시되는 바이트 수로 최종 확인하세요.
- 엔터: 2025학년도·2026학년도 기재요령은 둘 다 1Byte로 안내합니다. 엔터를 2Byte로 계산하는 안내 자료나 계산기도 있으니, 줄을 바꿔 쓴 글은 나이스 화면의 표시를 기준으로 삼으세요. `byte_count.py`는 `--newline-bytes 2`로 바꿔 셀 수 있습니다.

## 3. 어떤 항목에도 기재할 수 없는 것 (18–19쪽, 작성 시 유의사항 3번)

행동특성 및 종합의견을 포함해 학교생활기록부 어디에도 쓸 수 없습니다.

| 기호 | 내용 |
| - | - |
| 가 | 공인어학시험 참여 사실, 성적, 수상 실적 (TOEIC, TOEFL, TEPS, HSK, JPT, JLPT, DELF, DALF, 한자능력검정 등) |
| 나 | 교과·비교과 관련 교내·외 대회 참여 사실, 성적, 수상 실적 (교내 대회는 '수상경력' 항목에만 입력. 교외 대회는 학교장 허락을 받고 참가했어도 불가) |
| 다 | 교외 기관·단체(장)에게 받은 교외상 (표창장, 감사장, 공로상 포함) |
| 라 | 교내·외 인증시험 참여 사실이나 성적 |
| 마 | 모의고사·전국연합학력평가 성적과 관련 교내 수상 실적 |
| 바 | 논문을 학회지 등에 투고·등재하거나 학회에서 발표한 사실 |
| 사 | 도서 출간 사실 |
| 아 | 지식재산권(특허, 실용신안, 상표, 디자인 등) 출원·등록 사실 |
| 자 | 어학연수, 봉사활동 등 해외 활동 실적과 관련 내용 |
| 차 | 부모(친인척 포함)의 사회·경제적 지위를 짐작하게 하는 내용 (직종명, 직업명, 직장명, 직위명 등) |
| 카 | 장학생·장학금 관련 내용 |
| 타 | 구체적인 특정 대학명, 기관명(기구·단체·조직 포함), 상호명, 강사명 |
| 파 | 자격증 명칭과 취득 사실 ('자격증 취득 및 국가직무능력표준 이수상황' 항목 밖에서는 불가) |

"타"의 예외 (19쪽)
- 교육관련기관(교육부와 소속기관, 시도교육청과 직속기관, 교육지원청과 소속기관)의 이름은 쓸 수 있습니다.
- 봉사활동 실적의 '장소 또는 주관기관명'에는 구체적인 이름을 씁니다.
- 강사명은 학생이 참여한 강의나 교육활동의 강사를 가리킵니다.

## 4. 재학 중인 학교를 알 수 있는 내용 (19쪽, 유의사항 4번)

학교명, 재단명, 학교 축제명, 학교 별칭처럼 학교를 알 수 있는 내용은 인적·학적사항, 수상경력의 '수여기관', 봉사활동 실적의 '장소 또는 주관기관명'을 빼고는 어디에도 쓸 수 없습니다.

## 5. 세부능력 및 특기사항에 입력할 수 없는 것 (118쪽)

1. 위 3번과 4번(작성 시 유의사항)에서 금지하는 사항
2. 교내·외 대회 참여 사실, 성적, 수상 실적 (대회 이름을 단순 행사처럼 바꿔 적는 것도 불가)
3. K-MOOC, MOOC, KOCW 등 관련 사항
4. 방과후학교 활동
5. 연구보고서(소논문) 관련 사항 (정규 교육과정에서 작성이 가능한 일부 과목은 예외가 있음. 원문 확인)

## 6. 서술 원칙

- 교사가 직접 관찰하고 평가한 내용을 근거로 입력합니다(27쪽).
- 학생이 쓴 자료 가운데 활용할 수 있는 것은 동료평가서, 자기평가서, 수업 산출물(수행평가 결과물 포함), 소감문, 독후감으로 한정됩니다(27쪽).
- 세부능력 및 특기사항은 성취기준과 성취수준에 근거해 학생 개인의 성취 과정과 특성이 드러나게 쓰고, 수업 활동의 단순 나열이나 성취기준에 이미 있는 지식의 단순 서술은 피합니다(95쪽).
- 단순 사실을 과장하거나 부풀려 쓰는 것, 사실과 다른 내용을 쓰는 것은 신뢰도를 떨어뜨리는 사례로 꼽힙니다(19쪽, 유의사항 5번 가).
- 서술형 문장은 명사형 어미로 끝내고, 특수문자와 문단 구분 기호(번호)는 되도록 쓰지 않습니다(30쪽).
- 문자는 한글로 쓰되 부득이하면 영문을 씁니다. 일반화된 명사(CEO, PD, IT, SNS, PPT, AI 등)와 도서명·저자명 같은 고유 명사가 그 예입니다(28쪽).

## 7. AI와 학교생활기록부 (19쪽, 유의사항 5번 다)

- 기재요령은 "AI를 활용하여 생성한 자료를 학교생활기록부의 서술형 항목에 그대로 입력하는 행위"를 신뢰도를 떨어뜨리는 사례로 들고 있습니다.
- 글을 다듬는 보조 수단으로 생성형 AI의 도움을 받았다면, 최종 입력 전에 학생의 실제 수행과 무관한 허위·과장이 없는지와 기재요령의 유의사항을 지켰는지를 교사가 반드시 확인해야 합니다.
- 그래서 이 스킬은 글을 고쳐 쓰지 않고 지적만 합니다. 판단과 수정은 교사가 합니다.

## 8. 점검할 때 눈여겨볼 낱말

이 목록은 기재요령 원문이 아니라 점검을 돕기 위해 이 과정에서 만든 것입니다. 낱말이 있다고 모두 위반은 아니고, 없다고 안전한 것도 아닙니다. 문맥을 보고 "의심"으로만 보고합니다.

- 대회·수상: 대회, 경시, 올림피아드, 공모전, 수상, 입상, 금상·은상·동상, 대상, 표창, 감사장
- 시험·점수: TOEIC, TOEFL, TEPS, HSK, JLPT, 한자능력검정, 급수, 인증, 모의고사, 학력평가, 등급, 백분위, 자격증
- 기관·사람: ○○대학교, ○○학원, 주식회사, 재단, 연구소, 센터, 강사 이름, 교수 이름
- 가정 배경: 아버지·어머니·부모·삼촌 등과 함께 나오는 직업, 직장, 직위
- 교외·해외: 어학연수, 해외 봉사, 유학, 캠프, 투고, 등재, 학회, 출간, 특허, 출원, 장학금
- 세특 전용: 방과후학교, MOOC, KOCW, 소논문, 연구보고서
- 학교 식별: 학교 이름, 재단 이름, 축제 이름, 학교 별칭

- 공백과 문장부호, 그 밖의 특수문자를 나이스가 실제로 몇 Byte로 세는지 (2번의 "확인 필요" 참고)
- 시도교육청별 추가 지침과 학교 학업성적관리규정
