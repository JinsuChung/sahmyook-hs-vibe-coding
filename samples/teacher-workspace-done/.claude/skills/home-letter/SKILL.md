# 가정통신문 초안 쓰기

요청 내용: $ARGUMENTS
(위가 비어 있으면 대화에서 요청받은 내용을 따른다.)

## 절차

1. **필요한 정보 확인**: 아래 일곱 가지가 모두 있는지 본다. 요청과 `학사일정_2026-2.csv`에서 알 수 있는 것은 묻지 않고, 빠진 것만 한 번에 모아서 묻는다. 추측으로 채우지 않는다.
   - 제목(무엇을 알리는가)
   - 대상(학년, 학부모·학생)
   - 일시(날짜, 요일, 시작과 끝 시각)
   - 장소
   - 내용과 준비물
   - 회신 여부(회신이 있으면 기한과 내는 곳)
   - 문의처(부서와 전화)

2. **양식과 본보기 읽기**
   - `양식/가정통신문_양식.md`: 구성 순서, 문체 규칙, 틀
   - `보낸문서/`에서 파일 이름에 `가정통신문`이 들어간 문서 가운데 최근 2편: 인사말과 맺음말의 말투, 항목을 나누는 방식

3. **초안 쓰기**: 양식의 구성 순서를 그대로 따른다.
   - 호수는 `제 2026-〈번호〉호`로 비워 둔다. 번호는 사람이 붙인다.
   - 날짜에는 요일을 함께 적는다. 요일은 `학사일정_2026-2.csv`에 있는 날짜면 그 요일을 쓰고, 없는 날짜면 달력을 계산해서 확인한다.
   - 회신이 있으면 절취선 아래에 회신서를 붙이고, 없으면 "회신 없음"이라고 적는다.
   - 맨 아래에 `교육용 가상 데이터` 표기는 넣지 않는다(실습 자료에만 붙는 표기다).

4. **저장**: `보낸문서/YYYY-MM-DD_가정통신문_〈제목〉_초안.md` (날짜는 오늘, 제목의 띄어쓰기는 `_`로). 같은 이름이 있으면 덮어쓰지 않고 끝에 `_2`를 붙인다.

5. **스스로 점검**: [checklist.md](checklist.md)의 항목을 하나씩 확인한다. 바로 고칠 수 있는 것은 고쳐서 다시 저장하고, 사람이 정해야 하는 것은 남겨 둔다.

6. **확인 요청**: 아래를 짧게 보고하고 사람의 확인을 기다린다.
   - 저장한 파일 경로
   - 점검 결과(항목별 통과 / 확인 필요)
   - 사람이 정해야 하는 것(호수, 비워 둔 정보, 학사일정과 겹치는 일정 등)
   - "발송 전에 내용을 직접 확인해 주세요"라는 안내

## 항상 지킬 것

- 학생 개인을 알아볼 수 있는 정보(이름, 번호, 연락처, 성적, 상담 내용)는 통신문에 쓰지 않는다. 요청에 들어 있어도 빼고, 뺐다고 알린다.
- `양식/`, `받은공문/`, `보낸문서/`의 기존 파일은 고치지 않는다. 새 파일만 만든다.
- 이 스킬은 초안까지만 만든다. 인쇄, 발송, 게시는 사람이 한다.
