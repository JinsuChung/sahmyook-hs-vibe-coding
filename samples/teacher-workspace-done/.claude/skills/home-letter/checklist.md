# 가정통신문 점검표

초안을 저장한 뒤 항목마다 "통과" 또는 "확인 필요"로 답한다. "확인 필요"에는 이유를 한 줄 붙인다.

## 1. 날짜와 요일

- [ ] 본문의 모든 날짜에 요일이 붙어 있다.
- [ ] 날짜와 요일이 실제 달력과 맞는다. (`학사일정_2026-2.csv`에 있는 날짜는 그 요일과 같아야 한다.)
- [ ] 회신 기한이 발신 날짜보다 뒤이고, 행사 날짜보다 앞이다.
- [ ] 시작 시각과 끝 시각이 있고, 끝이 시작보다 늦다.

## 2. 학사일정과의 충돌

- [ ] 행사 날짜와 회신 기한이 `학사일정_2026-2.csv`의 지필평가 기간, 공휴일, 재량휴업일, 방학과 겹치지 않는다.
- [ ] 학사일정에 같은 행사가 있으면 날짜, 시각, 장소가 통신문과 같다.
- [ ] 겹치거나 다르면 고치지 말고 "확인 필요"로 남긴다. 어느 쪽이 맞는지는 사람이 정한다.

## 3. 빠진 정보

- [ ] 제목, 대상, 일시, 장소, 내용, 준비물, 회신 여부, 문의처가 모두 있다.
- [ ] 회신이 있으면 기한, 내는 곳, 회신서가 있다. 없으면 "회신 없음"이라고 적었다.
- [ ] 붙임을 말했다면 붙임 줄이 있고, 붙임이 없다면 붙임 줄도 없다.

## 4. 개인정보

- [ ] 학생 이름, 번호, 연락처, 성적, 상담 내용이 없다.
- [ ] 교사 개인 휴대 전화 번호가 없다. 문의처는 부서 전화다.
- [ ] 회신서에서 받는 정보가 꼭 필요한 것뿐이다.

## 5. 문체와 분량

- [ ] 본문이 "-습니다"체이고, 인사말이 두 문장을 넘지 않는다.
- [ ] "~하여 주시기 바랍니다"가 두 번을 넘지 않는다.
- [ ] 익일, 필히, 지참, 금번, 귀댁 같은 표현이 없다.
- [ ] 회신서를 뺀 본문이 공백 포함 900자 안팎(A4 한 쪽)이다.
- [ ] 발신 날짜와 `새봄고등학교장 (직인 생략)`이 있다.
