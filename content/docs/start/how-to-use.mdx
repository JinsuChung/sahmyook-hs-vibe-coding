수업 시간에는 강사 화면을 따라오고, 수업 뒤에는 혼자 다시 볼 수 있게 만든 사이트입니다. 자주 쓰는 기능 여섯 가지만 알아 두면 됩니다.

<Callout type="info" title="종이 교재가 필요하면">

## 프롬프트 카드: 복사해서 붙여 넣기

AI에게 보내는 요청문을 프롬프트라고 합니다. 이 사이트의 모든 프롬프트 상자에는 **복사** 버튼이 있습니다. 누른 뒤 Claude Code 입력창에 붙여 넣으세요 (<Kbd keys="mod+v" />).

<PromptCard id="explain-file" />

- **주황색 글자**는 내 상황에 맞게 바꿔 쓰는 빈칸입니다. 그대로 복사하면 예시 값이 들어갑니다.
- **빈칸 채우기**를 누르면 입력란이 열립니다. 입력한 값은 이 브라우저에 저장되어 다음에도 남아 있습니다.
- <b>왜 이렇게 쓰나요?</b>를 누르면 프롬프트를 이렇게 쓰는 이유와 아쉬운 예가 나옵니다.
- 별표(☆)를 누르면 [프롬프트 라이브러리](/prompts)의 즐겨찾기에 모입니다. 교무실에서 다시 꺼내 쓰기 좋습니다.

<Callout type="warn" title="빈칸에 실제 학생 정보를 적지 마세요">
  빈칸에는 파일 이름이나 과목 이름처럼 개인정보가 아닌 것만 적습니다. 실습은 가상 데이터로만 하고, 실제 학생의 이름·성적·상담 내용은 AI에 넣지 않습니다.
</Callout>

## 실습 단계: 체크하면 진도가 쌓입니다

실습은 단계별로 나뉘어 있습니다. 한 단계를 마치면 **이 단계 완료**를 누르거나 단계 번호 옆의 동그라미를 눌러 표시하세요. 회차 머리말과 왼쪽 사이드바에 진도가 쌓입니다.

<Callout type="info" title="진도는 기본적으로 이 브라우저에 저장돼요">
  아래의 **별명으로 참여**를 하면 다른 PC에서도 이어 할 수 있고 반 전체 현황에도 모입니다. 참여하지 않으면 이 브라우저에만 남고, 방문 기록이나 쿠키를 지우면 함께 지워집니다. 교무실 PC와 집 컴퓨터를 오가며 하신다면 참여해 두는 편이 편합니다.
</Callout>

## 예상 결과와 막혔을 때

- **이렇게 되면 성공** 상자는 그 단계를 마쳤을 때 Claude Code 화면에 나올 법한 모습입니다. 글자 하나하나가 같을 필요는 없습니다. AI의 답은 매번 조금씩 다르므로, 파일 개수나 합계처럼 핵심 내용이 맞는지 보세요.
- **막혔을 때** 상자에는 자주 생기는 증상이 모여 있습니다. 증상을 누르면 해결 방법이 펼쳐집니다.
- 그래도 안 되면 에러 메시지를 그대로 복사해 Claude Code에 붙여 넣으세요. 에러를 읽고 고치는 일도 AI가 잘하는 일입니다.

<PromptCard id="fix-error" compact />

같은 문제를 두 번 넘게 고쳐도 안 풀리면 대화를 비우고 다시 시작하는 편이 빠릅니다.

<PromptCard id="restart-fresh" compact />

## 깊이 파기: 수업 뒤에 혼자 차분히

회차마다 짝이 되는 **깊이 파기** 페이지(1.5, 2.5 …)가 있습니다. 수업에서는 굵직한 흐름만 따라가고, 왜 그런지에 대한 설명과 더 해 볼 실습은 이 페이지에 모아 두었습니다.

- 깊이 파기는 단계별로 걸리는 시간이 적혀 있습니다. 공강 시간에 한 단계씩 해도 됩니다.
- 회차 페이지 안의 **자세히** 상자도 같은 역할입니다. 수업 중에는 넘어가고, 나중에 펼쳐 읽으세요. 제목을 누르면 접고 펼 수 있습니다.
- 깊이 파기의 실습 단계도 체크하면 진도에 함께 쌓입니다.
- 하다가 생긴 질문은 적어 두었다가 다음 수업을 시작할 때 함께 풉니다.

## 우리 반 진행 현황에 참여하기

왼쪽 사이드바의 **별명으로 우리 반 현황에 참여하기**(또는 홈의 **별명으로 참여하기**)를 누르고 별명과 숫자 4자리 PIN을 정하면 됩니다.

- 참여한 뒤에는 실습 단계를 체크할 때마다 **자동으로** 반 전체 현황에 모입니다. 따로 저장 버튼을 누를 필요가 없습니다.
- 홈의 **우리 반 진행 현황**에서 과정별로 몇 명이 완료했는지 볼 수 있습니다. 회차 머리말에도 함께 듣는 선생님 가운데 몇 명이 완료했는지 보입니다.
- 다른 PC나 휴대폰에서는 **같은 별명과 PIN**으로 참여하면 진도가 합쳐져 이어집니다.
- 별명을 숨기고 싶으면 사이드바의 내 별명을 눌러 **내 참여 정보**를 열고 익명으로 바꿀 수 있습니다. **내 기록 지우기**도 그곳에 있습니다.

<Callout type="warn" title="실명 대신 별명을, PIN은 간단한 확인용으로">
  별명은 실명이나 교번 대신 편한 이름으로 정하세요. PIN에는 다른 곳에서 쓰는 비밀번호를 쓰지 않습니다. 저장되는 것은 별명, 암호화한 PIN, 실습 체크 현황뿐이고, 과제 칸에 쓴 글은 서버에 저장되지 않습니다. PIN을 잊으면 새 별명으로 참여하면 됩니다.
</Callout>

## 발표 모드 (수업 중 함께 보기)

강사가 프로젝터에 띄울 때 쓰는 모드입니다. 교과협의회나 동료 연수에서 이 사이트로 전달 연수를 하실 때도 쓸 수 있습니다.

| 키 | 동작 |
| --- | --- |
| <Kbd keys="P" /> 또는 상단 **발표 모드** | 켜기 / 끄기 |
| <Kbd keys="→" /> <Kbd keys="Space" /> | 다음 슬라이드 |
| <Kbd keys="←" /> | 이전 슬라이드 |
| <Kbd keys="T" /> | 실습 타이머 |
| <Kbd keys="Q" /> | 지금 페이지 QR 코드. 휴대폰으로 같은 위치 열기 |
| <Kbd keys="esc" /> | 발표 모드 끝내기 |

발표 모드에서는 본문이 소제목 단위로 한 화면씩 나뉩니다.

## 그 밖의 기능

- **검색**: 상단 검색창(<Kbd keys="mod+K" />)에서 회차 본문, 프롬프트, 용어를 찾을 수 있습니다.
- **용어**: 본문에서 점선 밑줄이 그어진 낱말은 용어입니다. 마우스를 올리거나 누르면 뜻과 비유가 나옵니다. 전체 목록은 [용어사전](/glossary)에 있습니다.
- **실습 도구**: [프롬프트 빌더](/lab/prompt-builder), [API 비용 계산기](/lab/cost-calculator), 눌러 보며 익히는 [개념 시뮬레이터](/lab/simulators)가 있습니다. 실제 AI를 부르지 않아서 비용이 들지 않습니다.
- **인쇄**: 각 페이지 위쪽의 **인쇄 / PDF** 버튼을 누르면 사이드바와 버튼을 뺀 모양으로 인쇄됩니다.
- **실습 자료**: 회차별 실습 폴더는 [자료실](/downloads)에서 내려받습니다. 모두 가상 데이터입니다.
