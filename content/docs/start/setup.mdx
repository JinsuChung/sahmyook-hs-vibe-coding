화면 위쪽의 **Windows / macOS** 토글을 바꾸면 설명이 운영체제에 맞게 바뀝니다.

<Callout type="info" title="처음이라면 가입부터">
  Claude·GitHub·Vercel 가입과 Claude 유료 플랜 결제, 데스크톱 앱 설치를 한 번에 따라 하는 순서는 [연수 전 준비: 가입과 설치](/start/signup)에 있습니다.
</Callout>

## 언제 무엇이 필요한가요

1회차에는 Claude 데스크톱 앱만 있으면 됩니다. 나머지는 표의 회차가 되기 전에 준비하세요.

| 준비할 것 | 처음 쓰는 회차 | 비고 |
| --- | --- | --- |
| [Claude 데스크톱 앱](#claude-code) | 1회차 | 과정 전체에서 씁니다. 유료 플랜 계정 필요 |
| [Python](#python) | 2회차 | 엑셀 처리용. Claude Code가 설치를 안내해 주기도 합니다 |
| [Git](#git) | 3회차 | 커밋과 되돌리기 |
| [Node.js](#nodejs) | 3회차 | 웹앱을 내 PC에서 띄울 때 |
| [GitHub 계정](#accounts) | 3회차 | 저장소 올리기 |
| [Vercel 계정](#accounts) | 3회차 | 배포 |
| [Supabase 계정](#accounts) | 4회차 | 데이터베이스 |
| [Claude Console 계정](#accounts) | 4회차, 8회차 | 내 앱에서 쓸 API 키 |

2부(5–8회차)에서 새로 설치할 프로그램은 없습니다. 5–7회차는 Claude 데스크톱 앱으로 진행하고, 8회차는 3–4회차에 준비한 것을 그대로 씁니다. 7회차의 예약 작업은 앱이 최신 버전이어야 하니, 그 전에 앱을 한 번 업데이트해 두세요.

<Callout type="warn" title="학교 업무용 PC로 실습하신다면">
  설치 권한, 학교 무선망, 그리고 PC에 들어 있는 학생 정보 때문에 미리 챙길 것이 있습니다. 설치를 시작하기 전에 아래 [학교 PC 특수 상황](#school-pc)을 먼저 읽어 주세요.
</Callout>

## Claude 데스크톱 앱 [#claude-code]

Claude Code는 Claude 데스크톱 앱의 **Code** 탭 안에 들어 있습니다. 터미널(검은 명령 창)을 쓰지 않아도 되어서 처음 시작하기에 가장 편합니다.

- 필요한 플랜: <Fact k="claude.plan" />
- 컴퓨터 사양: <Fact k="claude.os" />

<Steps>
<FdStep>
[claude.com/download](https://claude.com/download)에서 운영체제에 맞는 Claude 앱을 내려받아 설치합니다.
</FdStep>
<FdStep>
앱을 열고 Claude 계정으로 로그인합니다. Windows는 시작 메뉴, macOS는 응용 프로그램 폴더에서 **Claude**를 찾으면 됩니다. 비밀번호와 인증 코드는 본인이 직접 입력합니다.
</FdStep>
<FdStep>
사이드바 위쪽의 **Code** 탭을 누릅니다. 탭이 아이콘으로만 보이면 마우스를 올려 이름을 확인하세요. 업그레이드 안내가 나오면 유료 플랜에 먼저 가입해야 합니다.
</FdStep>
<FdStep>
입력창 아래 줄의 첫 번째 칸(환경 선택)에서 **Local** 묶음의 맨 위 항목을 고르고, 그 옆의 폴더 칸에서 <b>Open folder…</b>를 눌러 작업할 폴더를 선택합니다. 자료실에서 내려받아 압축을 푼 **실습 폴더**를 고르세요.
</FdStep>
<FdStep>
입력창에 `이 폴더에 어떤 파일이 있는지 알려줘`라고 써 보세요. 답이 오면 준비가 끝났습니다.
</FdStep>
</Steps>

데스크톱 앱에는 Claude Code가 들어 있어서, Code 탭을 쓰는 데 Node.js나 터미널용 Claude Code를 따로 설치할 필요가 없습니다.

<Callout type="info" title="화면이 설명과 다르다면">
  앱은 자주 바뀝니다. 메뉴 이름이나 위치가 다르면 [공식 문서의 데스크톱 앱 시작하기](https://code.claude.com/docs/en/desktop-quickstart)를 확인하세요. 로그인이나 접속이 안 되면 아래 [학교 무선망](#school-network) 항목을 보세요.
</Callout>

가입과 결제, 비밀번호 입력은 모두 본인이 직접 합니다. AI에게 비밀번호를 알려 주지 않습니다.

| 계정 | 처음 쓰는 회차 | 가입하는 곳 | 알아 둘 점 |
| --- | --- | --- | --- |
| Claude | 1회차 | [claude.ai](https://claude.ai) | <Fact k="claude.plan" /> |
| GitHub | 3회차 | [github.com](https://github.com) | 코드를 올려 두는 곳. 개인 계정 하나면 됩니다 |
| Vercel | 3회차 | [vercel.com](https://vercel.com) | 웹앱을 인터넷에 올리는 곳. Hobby 요금제: <Fact k="vercel.hobby" /> |
| Supabase | 4회차 | [supabase.com](https://supabase.com) | 데이터베이스. 무료 요금제: <Fact k="supabase.free" /> |
| Claude Console | 4회차, 8회차 | [platform.claude.com](https://platform.claude.com) | 내 앱에서 Claude를 부를 때 쓰는 API 키를 만드는 곳 |

<Callout type="info" title="Claude 구독과 Claude API는 따로 계산됩니다">
  Claude Code를 쓰는 구독 요금과, 내가 만든 앱이 Claude를 부를 때 드는 API 요금은 별개입니다. API는 Claude Console에서 크레딧을 충전해 쓴 만큼 냅니다. 4회차와 8회차 실습에 드는 비용은 [API 비용 계산기](/lab/cost-calculator)로 미리 어림해 볼 수 있습니다.
</Callout>

## 학교 PC 특수 상황 [#school-pc]

학교 업무용 PC는 집 컴퓨터와 다릅니다. 세 가지를 미리 확인하세요.

### 설치 권한이 막혀 있을 때

설치 파일을 실행했는데 관리자 암호를 묻거나 차단 안내가 나오면, 그 PC는 프로그램 설치가 제한된 상태입니다.

- **연수 전에 미리 협의하세요.** 정보부장이나 전산 담당 선생님께 아래 목록을 전하고 설치를 요청합니다. 당일에 요청하면 수업 시간을 놓치기 쉽습니다.
- **개인 노트북을 쓰는 것도 방법입니다.** 실습 자료는 모두 가상 데이터라서 학교 밖 컴퓨터에서 해도 문제가 없습니다.
- **보안 설정을 우회하지 않습니다.** 학교 PC의 제한은 이유가 있어서 걸려 있습니다. Claude Code가 우회 방법을 제안하더라도 승인하지 마세요.

| 요청할 프로그램 | 필요한 회차 | 내려받는 곳 |
| --- | --- | --- |
| Claude 데스크톱 앱 | 1회차부터 | claude.com/download |
| Python | 2회차 | python.org/downloads |
| Git (Windows는 Git for Windows) | 3회차부터 | git-scm.com/downloads |
| Node.js LTS | 3회차부터 | nodejs.org |

무엇이 막혀 있는지 모르겠다면 Claude Code에게 확인만 시켜 볼 수 있습니다.

<PromptCard id="school-pc-check" compact />

### 학교 무선망이나 보안 프로그램 때문에 접속이 안 될 때 [#school-network]

Claude Code는 인터넷 연결이 있어야 동작합니다. 앱을 열었는데 로그인 화면이 나오지 않거나, 빈 화면만 보이거나, 연결할 수 없다는 안내가 나오면 학교 망이나 보안 프로그램이 접속을 막고 있을 수 있습니다.

- **꼭 열려 있어야 하는 주소**: <Fact k="claude.network" />. 전체 목록은 [공식 문서의 네트워크 요구 사항](https://code.claude.com/docs/en/network-config#network-access-requirements)에 있습니다. 전산 담당 선생님께 이 문서 주소를 함께 전하면 확인이 빠릅니다.
- **3회차부터 더 필요한 주소**: github.com, vercel.com, 그리고 4회차의 supabase.com입니다.
- **망 문제인지 가려내기**: 개인 노트북이라면 다른 인터넷(예: 휴대폰 테더링)에 연결해 같은 증상이 나는지 봅니다. 다른 망에서 잘 되면 학교 망의 차단이 원인입니다.
- **업무용 PC를 임의로 다른 망에 연결하지 마세요.** 망 연결 규정은 학교와 교육청마다 다릅니다. 전산 담당 선생님과 먼저 상의하세요.

### 업무용 PC에는 학생 정보가 많습니다: 실습 폴더만 여세요

Claude Code는 선택한 폴더를 작업장으로 삼아 그 안의 파일을 읽고 고칩니다. 그래서 **어느 폴더를 여는지**가 가장 중요한 안전장치입니다.

- **실습용 폴더를 따로 만들고 그 폴더만 엽니다.** 자료실에서 내려받은 실습 자료의 압축을 그 안에 풉니다.
- **바탕화면 전체, 문서 폴더 전체, 교무실 공유 드라이브를 통째로 열지 않습니다.** 성적, 상담 기록, 출결, 건강 정보가 든 파일이 함께 들어 있기 쉽습니다.
- **나이스(NEIS)에서 내려받은 원본 파일이 있는 폴더는 열지 않습니다.** 실습은 가상 데이터로만 합니다.
- **권한 승인 창은 읽고 누릅니다.** Claude Code가 폴더 밖의 파일을 보려고 하거나 예상하지 못한 명령을 실행하려 하면 거부하고 이유를 물어보세요.

과정이 끝난 뒤 실제 업무에 쓸 때도 같습니다. 학생 정보가 없는 업무(양식 정리, 일정 정리, 안내문 초안)부터 시작하고, 학생 정보가 필요한 일은 가명 처리와 학교·교육청 지침을 먼저 확인합니다.
