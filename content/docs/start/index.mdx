서울삼육고등학교 선생님을 위한 과정입니다. 8회차를 마치면 **내 업무에 필요한 작은 도구를 말로 만들어 쓰고, 반복되는 일을 맡길 에이전트를 직접 길러 내고, 학생이 쓰는 교육용 AI를 책임 있게 설계**할 수 있습니다.

<Callout type="warn" title="이 과정의 약속 세 가지">

1. **실습은 가상 데이터로만 합니다.** 모든 실습 자료는 가상의 학교인 새봄고등학교의 것입니다. 나이스(NEIS)에서 내려받은 원본 파일은 실습에 쓰지 않습니다.
2. **학생 정보는 AI에 넣지 않습니다.** 실제 학생의 이름, 학번, 성적, 상담 내용, 건강·가정 정보를 AI에 입력하지 않습니다. 꼭 필요한 일이라면 가명으로 바꾸고, 학교와 교육청의 지침, 개인정보 보호법을 따릅니다.
3. **평가와 기록의 최종 판단은 교사가 합니다.** AI는 초안을 쓰고, 점검하고, 취합하는 일을 돕습니다. 성적과 학교생활기록부의 책임은 교사에게 있고, 근거는 선생님이 직접 관찰한 학생의 활동입니다.

</Callout>

## 누구를 위한 과정인가요

| 항목 | 내용 |
| --- | --- |
| 대상 | 서울삼육고등학교 선생님. 교과, 담임, 부장, 업무 담당 누구나 (코딩 경험이 없다고 가정합니다) |
| 강의 | 정진수 |
| 방식 | 회차당 50분, 한 차시입니다. 개념 → 시연 → 실습 → 정리 순서로 진행하고, 두 회차를 묶어 2시간 연수로도 운영합니다 |
| 도구 | Claude Code (Claude 데스크톱 앱의 Code 탭) |
| 결과물 | 회차마다 "내 컴퓨터에 남는 것" 하나 |

코딩 문법을 배우는 과정이 아닙니다. 평가계획서를 쓰듯 **무엇을 원하는지 글로 정하고, AI가 세운 계획을 읽고 승인하고, 결과가 맞는지 확인하는 법**을 익힙니다. 만드는 일은 AI가 하고, 정하고 확인하는 일은 선생님이 합니다.

## 8회차 구성

### 1부 · 바이브 코딩 기초 (1–4회차)

내 PC의 작은 도구에서 시작해 링크로 나누는 웹앱까지 갑니다.

| 회차 | 주제 | 만드는 것 | 주요 도구 |
| --- | --- | --- | --- |
| [1](/sessions/1) | 바이브 코딩에서 에이전틱 엔지니어링으로 | Claude Code 설치, 교무실 공유폴더 부서별 정리와 현황 보고서 | Claude Code 데스크톱 앱 |
| [2](/sessions/2) | 인스턴트 소프트웨어: 쓰고 지우는 내 업무 도구 | 반별 수행평가 점수 취합기, 제출물 파일 정리, 한 장짜리 HTML 도구 | 플랜 모드, CLAUDE.md |
| [3](/sessions/3) | 안전망과 공유: Git·GitHub, 그리고 배포 | 커밋 이력이 있는 GitHub 저장소, 링크로 공유하는 수행평가 일정 보드 | Git, GitHub, Vercel |
| [4](/sessions/4) | 데이터와 AI를 붙인 웹앱 | 화면에서 등록·수정되는 보드, 평가계획 문서에서 일정을 뽑아 주는 AI 기능 | Supabase, Claude API |

### 2부 · 에이전트 개발 (5–8회차)

반복 업무를 맡기는 업무 에이전트에서 시작해 학생이 쓰는 교육용 에이전트까지 갑니다.

| 회차 | 주제 | 만드는 것 | 주요 도구 |
| --- | --- | --- | --- |
| [5](/sessions/5) | 내 업무를 맡기는 에이전트: 반복 업무에서 시작하기 | 교무수첩 업무 폴더, 가정통신문 스킬, 공문 요약 스킬 | CLAUDE.md, 스킬 |
| [6](/sessions/6) | 에이전트 키우기: 스킬·서브에이전트·연결 | 생기부 문구 점검 스킬, 검토 전담 서브에이전트 | 스킬, 서브에이전트, MCP |
| [7](/sessions/7) | 스스로 도는 에이전트: 예약 실행과 자동화 | 월요일 아침 주간 업무 브리핑, 공문함 자동 정리 | 예약 작업, 헤드리스 실행, 훅 |
| [8](/sessions/8) | 교육용 에이전트 만들기, 그리고 책임 있게 쓰기 | 배포된 과목 학습 도우미, 내 에이전트 운영 계획 | Claude API, 시스템 프롬프트 |

실습은 세 가지 프로젝트로 이어집니다.

- **수행평가 일정 보드** (3–4회차): 학년·과목별 수행평가 마감을 D-day 순으로 보여 주는 웹앱입니다. 개인정보가 없어서 공개해도 안전한 주제입니다.
- **교무수첩 업무 폴더** (5–7회차): 교사 한 사람의 업무 폴더를 에이전트의 작업장으로 만들고, 스킬과 예약 작업을 하나씩 붙여 갑니다.
- **새봄 학습 도우미** (8회차): 답을 바로 주지 않고 질문으로 이끄는 과목 튜터 웹앱입니다.

## 수업에서는 굵직하게, 수업 뒤에는 깊이

50분 수업에 모든 것을 담을 수는 없습니다. 그래서 이 사이트는 회차마다 두 장으로 되어 있습니다.

| 페이지 | 언제 보나요 | 무엇이 들어 있나요 |
| --- | --- | --- |
| **회차** (1, 2, 3 …) | 수업 시간에 함께 | 굵직한 흐름입니다. 짧은 개념, 시연, 따라 하는 실습, 정리와 복습 퀴즈 |
| **깊이 파기** (1.5, 2.5, 3.5 …) | 수업 뒤에 혼자 차분히 | 왜 그런지에 대한 설명, 혼자 따라 하는 미션, 예상 결과, 막혔을 때의 해결법, 내 업무에 적용해 보기 |

회차 페이지 안에서도 수업에서 다 다루지 못한 이야기는 **자세히** 상자에 접어 두었습니다. 수업 중에는 넘어가고, 나중에 펼쳐 보시면 됩니다. 깊이 파기를 하다가 생긴 질문은 적어 두었다가 다음 수업을 시작할 때 함께 풉니다.

| 깊이 파기 | 혼자 해 볼 것 | 걸리는 시간 |
| --- | --- | --- |
| [1.5](/sessions/self-1) | Claude Code와 친해지기: 지시하는 법, 계획 보기, 되돌리기, 문서 맡기기와 한글(HWP) 파일 | 약 90분 |
| [2.5](/sessions/self-2) | 엑셀·파일 도구 더 만들기: 검증 기준 쓰기, 출결·설문·점수 분포 작업 | 약 90분 |
| [3.5](/sessions/self-3) | 커밋하는 습관과 혼자 배포하기: 되돌리는 세 가지 방법, 처음부터 혼자 배포 | 약 110분 |
| [4.5](/sessions/self-4) | 데이터·보안·AI 기능 손에 익히기: SQL과 RLS 읽기, 비용 어림, 숨은 지시문 시험 | 약 110분 |
| [5.5](/sessions/self-5) | 스킬 다듬기와 내 업무 지도 그리기: 스킬이 불리는 조건 시험, 맡길 일 고르기 | 약 110분 |
| [6.5](/sessions/self-6) | 스크립트 붙이기와 연결 넓히기: 계산은 스크립트에게, 서브에이전트 설계 | 약 110분 |
| [7.5](/sessions/self-7) | 자동화 운영하기: 실행 기록 읽기, 권한 좁히기, 자동화하면 안 되는 일 | 약 110분 |
| [8.5](/sessions/self-8) | 과정 이후 4주 로드맵: 내 에이전트 하나를 실제 업무에 올리고 동료와 나누기 | 4주 동안 약 150분 |

한 번에 몰아서 하지 않아도 됩니다. 깊이 파기는 대부분 10–30분짜리 단계 다섯 개로 나뉘어 있어서, 공강 시간에 한 단계씩 해도 충분합니다.
